# devdeck brand

Vector logo, wordmark and icons for devdeck, rebuilt from the concept as clean SVG.
"dark" files are for **dark backgrounds**; "light" files are for **light backgrounds**. Every PNG has a transparent background unless noted.

| File | Use |
|---|---|
| `logo-mark-dark.svg` / `logo-mark-light.svg` | the D mark (prompt `>_` is mint on dark, black on light) |
| `wordmark-dark.svg` / `wordmark-light.svg` | "devdeck" (Geist Bold, outlined, so no font needed) |
| `lockup-dark.svg` / `lockup-light.svg` | mark + wordmark side by side (headers, README, slides) |
| `app-icon.svg` | rounded dark tile with the mark (desktop app, Wails) |
| `app-icon-square.svg` | same tile without rounding (platforms that round corners themselves) |
| `favicon.svg` | browser tab icon; switches the prompt colour with the OS theme |
| `png/logo-mark-{dark,light}-{512,1024}.png` | raster mark |
| `png/wordmark-{dark,light}-1600.png` | raster wordmark (1600 × 300) |
| `png/lockup-{dark,light}-2000.png` | raster lockup (2000 × 444) |
| `png/app-icon-{512,1024}.png` | app icon (Wails `build/appicon.png` uses the 1024 one) |
| `png/apple-touch-icon-180.png` | iOS home-screen icon (opaque square) |
| `png/favicon-{16,32}.png` | favicon fallbacks |
| `png/brand-sheet.png` | everything on one sheet, dark and light |
| `preview.html` | open in a browser to see all files on dark and light backgrounds |

## Clear space and minimum size

- Keep at least **¼ of the mark's height** of empty space around the mark and the lockup.
- Below **24 px**, use `app-icon` or the favicons; the plain mark's prompt gets too small.

## Rebuilding

The SVGs were generated by a script (Geist Bold outlined with opentype.js, gradients from the concept's sampled colours) and rendered to PNG with headless Chrome. Edit the SVGs directly in Inkscape or Figma, or ask Claude to regenerate with changes (another font, other colours, rounder corners).
