Stacks

A stack is a named file listing which services to start and how. Make as many as you like and start whichever one you need.

Example stack file

name: backend-only
checks: [docker, go]               # Doctor checks run before start; stop with a clear message if missing
compose: docker-compose.deps.yml   # started first
services:
  - repo: infrabot-auth-service
    run: go run ./cmd/server
    port: 8081
    ready: http://localhost:8081/health
    logs: zerolog                  # log parser plugin → levels, fields, file:line
  - repo: infrabot-ticket-service
    run: go run ./cmd/server
    port: 8083
    after: [infrabot-auth-service]
    env_file: .env.local

Under the hood this can be turned into a Tiltfile (or process-compose file). The stack YAML is what you edit.
