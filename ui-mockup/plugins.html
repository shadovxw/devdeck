Plugins (tools)

Every tool is a plugin. A plugin says what actions (flow steps) it offers, what inputs/outputs they have, which binary it needs, and which connection type it uses. Code is static, but adding a tool is one folder + one line in a registry.

Adding a new tool (e.g. hadolint)

plugins/hadolint/
  manifest.yaml     id, category, needs: [hadolint], install: winget/scoop/mise cmd, actions + their inputs/outputs
  hadolint.go       implements the Plugin interface: Check(), Actions(), Run(action, inputs) → outputs, findings
registry.go         + register(hadolint.New())     ← the only line touched outside the folder
