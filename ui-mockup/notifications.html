Notifications

Get told when something needs you: a service won't come up, a Docker build finishes or fails, a flow fails. Every channel sends over HTTPS (port 443), so it works on the office network where SMTP (ports 25/465/587) is blocked.

General

Quiet hours: [22:00] – [08:00] (phone and email held, desktop still shows)   ☑ Batch emails into one message per 15 min
☑ Never include log lines, SQL, tokens or file contents in messages, only names, status and a "open in devdeck" link
☑ Queue and retry if the internet is down
