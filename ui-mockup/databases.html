What Claude can see

Instead of reading 56 migration files across 9 repos, Claude reads what devdeck already knows:
  • Schema snapshots: .devdeck/context/db/<database>.md (tables, columns, FKs, which service owns it, which file defines it). Refreshed after every migrate.
  • devdeck MCP server (read-only DB role): tools like list_tables, describe_table, run_select, run_saved_script. Write scripts still need your click.
