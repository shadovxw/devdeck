Where the numbers come from

  • Containers: Docker Engine API stats (the same data as docker stats).
  • Go / node / python processes started by devdeck: per-process CPU and RAM via gopsutil, using the process IDs devdeck already knows.
  • Whole machine, CPU history: gopsutil, sampled every 5 s and kept for 24 h.
  • Disk: docker system df plus folder sizes.
